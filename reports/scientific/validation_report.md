# Независимая научная проверка

Статус: not_started. Предсказания не зарегистрированы, проверочные данные не раскрывались в рамках этого проекта. Инженерный L0 smoke не является проверкой распространённости субспутников.

При выполнении указать prediction_id, split version, run_id, критерии, численный результат с uncertainty, supported/contradicted/inconclusive и любое использование результата для изменения модели.
