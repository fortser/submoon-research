# Завершение W0 и приёмка входов W1

Дата: 5 октября 2026. Задачи W0-T002/W0-T006; исполнитель `codex-w0-completion-20261005`. Основание: полный раздел W0 научной программы, [аудит качества](W0_quality_review_20261004.md), W0-P002 и решение [W0-D011](../../docs/decisions/W0-D011_nominal_completion.md).

W0 имеет проверенный продукт для перехода к W1: явную номинальную постановку, прослеживаемые параметры, воспроизводимые геометрические и пробные старты, малый реальный ансамбль трёх хозяев и статус каждой неоднозначности. Принимается собственное независимое воспроизведение. Точное повторение недоступного авторского интегратора, реальные контактные поверхности и совместные распределения ошибок не объявляются восстановленными. Все требования завершения W0 проверяются по продуктам ниже; полный W1/W2 и основной атлас требуют собственных ворот.

Аудит номиналов: **W0-nominal-20261005T110014Z-d605ac09**; повторная генерация подтверждается финальной приёмкой.

## 4. Численные проверки и базовый ансамбль

V02 v2 сохраняет исходные допуски: координаты/скорость 1e-8, энергия/момент 1e-9 в безразмерном контроле. Эталон mpmath решает задачу фактически округлённого binary64 старта с 60 и 80 знаками; ошибка прежнего сравнения с идеальными a/e отдельно диагностирована. При e=0.99 малое округление энергии начального состояния накапливало фазовую разность, особенно заметную в перицентре.

**W2-analytic-20261005T103304Z-f4311c42** passed в явно объявленной области: IAS15 для e=0,0.5,0.9,0.99; DOP853 для e=0,0.5. IAS15 e=0.99: ошибка положения 6.64e-12, скорости 4.69e-9. DOP853 e=0.9/0.99 сохраняется непринятым; этот отказ не удалён и не превращён в успех всей сетки. Старый failed V02 run `W2-analytic-20261005T085951Z-103e3d09` сохранён. IAS15 PRS23/epsilon и DOP853-допуски фиксируются отдельно, LL=13 не переносится.

**W2-nominal-controls-20261005T110233Z-98ede168**: CR3BP L4/L5, 10 периодов, drift Якоби 4.44e-16; две J2-прецессии за 80 периодов соответствуют независимым формулам лучше 0.015% при критерии 1%, drift энергии <1.94e-11. Unit-проверки отдельно сверяют градиент потенциала, реакцию и инерциально-относительную формулу, поэтому допуск не основан только на согласии двух интеграторов.

Малый ансамбль: 4 a ×3 наклонения на хозяина, e=0; по 5 начальных периодов, один пробный объект в каждом независимом расчёте. DOP853 rtol=1e-11 и повтор 1e-13; проверочный IAS15 в 12 случаях. Максимальная нормированная разность положений при уточнении 9.87684e-7, скоростей 4.32473e-7 при предзаданном допуске 1e-6. Максимум IAS15 по сохранённым отсчётам: 8.99667e-7 по положению и 3.91203e-7 по скорости. Максимальный относительный drift энергии массивной подсистемы 3.80e-15.

34 орбиты дошли до checkpoint; продолжение из сохранённых состояний совпало с сегментированным первичным расчётом. Две другие завершились контактом раньше. Проверяются SHA байтов и соответствие модели, GM, исходного старта, горизонта и численного режима; неправильные значения отклоняются отрицательными тестами. ## 7. Сквозная приёмка и воспроизведение

Машинное доказательство: [W0_completion_v1.json](../../results/evidence/W0_completion_v1.json), реестр утверждений `claims.csv`; итоговый проверочный run указан в доказательстве. Проходят 132 pytest, Ruff, project validate, актуальность досье, L0, номинальный аудит/точное повторение каталога, выравнивание/replay, старый строгий L1 v0.3 и ожидаемый отказ архивного аудита. В приёмке сверены зарегистрированные SHA окончательного ансамбля, его входы, код и checkpoint; повторены собственные сетки и генератор реальных областей. Один первоначальный приёмочный run завершился ошибкой типа numpy.bool_ в отчётном агрегаторе; исправлен без изменения научных исходов, failed run сохранён.

```powershell
.venv/Scripts/python.exe -X utf8 scripts/adopt_nominal_model.py
.venv/Scripts/python.exe -X utf8 scripts/acquire_planetary_alignment.py --replay runs/W0-alignment-20261005T105116Z-afdac2eb

```

Команды создают новые runs. По умолчанию аудит номиналов/alignment не публикует принятый файл повторно; `--publish` допустим только для ещё отсутствующей версии. Данные/runs восстановимы из выпуска; инструкция и фактическая проверка — [restore_protocol_v2](../../docs/architecture/restore_protocol_v2.md) и [backup_restore_v2.json](../../results/evidence/backup_restore_v2.json).
