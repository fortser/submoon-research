# W2-T073: версионный контракт снимка на входе freeze

Evidence/run_id: `W2_T073_freeze_contract_20261103T103843Z`. Решение W2-D051, архитектура D050 принята отдельно от приёмки реализации. Проверка W2-C130; исходный дефект W2-C129/I045.

## Изменение

Добавлен `contracts/run_manifest.py::validate_run_manifest_for_admission`; `contracts/freeze.py` вызывает его сразу после чтения pilot manifest через прежний InputLedger. Сам guard не читает файлов и не создаёт новую систему хеширования. Прежний маршрут freeze затем проверяет SHA всех перечисленных копий, артефактов и входов, а также научные ворота.

Для RunContext 0.3 обязательны complete, непустые уникальные нормализованные относительные expected_paths, целочисленный published_count (не bool), равный длине списка, и наличие всех ожидаемых путей в корректном code_sha256. Дополнительные поздние записи разрешены и проходят существующую проверку байтов. Отсутствующие/неизвестные версии не получают fallback. Явный 0.2 без marker проходит прежний маршрут без утверждения полноты начального набора; 0.2 с новым marker отклоняется как противоречие форматов.

Изменения production ограничены новым контрактом и двумя строками freeze (import + вызов). `execution.py`, InputLedger, atomic_text, научные критерии/формулы/runner не менялись в этом продолжении. В старой отрицательной fixture короткого пилота добавлена явная schema_version=0.2, прежний ожидаемый отказ «Короткий benchmark» сохранён. Новые tests находятся в `tests/unit/test_run_manifest_freeze.py`.

Контракт предназначен для допуска, а не общего диагностического чтения pending/failed. Специализированные PH3/B144 манифесты не являются RunContext: их нельзя автоматически перенести на эту схему по совпадению поля code_sha256.

## Бюджет, воспроизводимость и ограничения

Команды, времена, returncode, наблюдённые Windows PID/create_time/RSS и остаточные процессы — `attempts.jsonl`. Учтён консервативный прежний резерв **240 s**, а не обнуление общего лимита T073 600 s. Все новые попытки ограничены ≤60 s, одиночные CLI ≤30 s; свободный диск проверялся до старта, evidence ограничены 256 MiB. Windows-наблюдаемые процессы по окончании попыток не остались. WSL запускался только в явной Ubuntu-24.04 с собственным timeout; Windows sampling не измеряет полный Linux RSS и не является доказательством отсутствия всех возможных Linux-потомков. Полные OS memory quota и power-loss durability не заявляются.

Точные SHA источников, их сохранённые копии, окружение и итог расхода — `manifest.json`. Существующие научные runs и прежние evidence не переписывались. Новый L0 smoke — отдельный run.

I045 исправлена в проверенной области, но независимый review другим исполнителем не проводился; статус fixed, не verified. Согласованность snapshot/байтов не защищает от согласованной подмены всей цепочки свидетельств и не доказывает физику. Наличие полного snapshot не означает научный допуск.
