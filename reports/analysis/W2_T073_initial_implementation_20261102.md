## Что сделано

В `src/submoon_research/execution.py` начальный снимок кода публикуется в две записи manifest: ранний `pending` с ожидаемыми путями и итоговый `complete` с индексом SHA. Для новых запусков указывается версия 0.3; старые runs не мигрируются. SHA считается из того же буфера, что передаётся записи копии; неполная запись отклоняется. Тело `with` не начинается до возврата финальной публикации. Отдельный `save_code` после входа по-прежнему публикуется немедленно. `tracking.atomic_text`, fsync и InputLedger не менялись.

При исключении копирования/commit сохраняется исходная ошибка; если финализация тоже упала, её ошибка доступна через цепочку исключений. Доступный для записи manifest получает состояние snapshot `failed`, а при недоступной публикации может остаться ранний `pending`. Пакетный индекс staging не публикуется по частям. Внешний kill не выполняет финализацию.

Изменения ограничены `src/submoon_research/execution.py` и новым `tests/unit/test_provenance_batch.py`. Подготовительные helpers лежат в `scratch/`; до патча сохранены SHA, копия baseline и git status. Научные модули и старые артефакты не редактировались.
