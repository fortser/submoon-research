Рабочий проект программы W0–W10. Первый научный продукт — сопоставимый атлас конечновременной выживаемости W0–W3 с ограниченным исследованием механизмов W4.

Пользовательское оглавление: **[PROJECT_MAP.md — что где находится](PROJECT_MAP.md)**. Карта обновляется вручную по отдельному запросу.

Описание для пользователя: **[TRACKING_SYSTEM.md — алгоритм, блок-схемы и чтение контекста](TRACKING_SYSTEM.md)**.

Для серий, не укладывающихся локально в 5–6 часов, действует [порядок подготовки аренды Vast.ai](docs/compute_policy.md). Любая аренда и трата денег требуют прямого разрешения пользователя на конкретный план.

Научный контекст без перечитывания всей программы: [общая картина](docs/context/project_overview.md) → [досье W0–W10](docs/stages/README.md) → обязательные тематические блоки и фактические продукты предыдущих этапов.

Последовательность, параллельные ветви и пересмотр плана: **[RESEARCH_ROADMAP.md](RESEARCH_ROADMAP.md)**.

Начать с [STATE.md](STATE.md), [плана](PLAN.md), [правил агента](AGENTS.md) и [первой задачи W0-001](docs/tasks/W0-001.md). Полные исходные документы: [научная программа](Научная_программа_субспутники.md) и [организация](Организация_исследования_и_инструменты.md).

## Быстрый старт в PowerShell

Из корня проекта, без активации окружения и без сети:

```powershell
.\.venv\Scripts\python.exe scripts/project.py doctor
.\.venv\Scripts\python.exe scripts/project.py validate
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe scripts/project.py smoke
.\.venv\Scripts\python.exe -m ruff check src scripts tests
```

`doctor` показывает доступность локальных зависимостей, `validate` проверяет каркас и контрольные суммы исходных документов. `smoke` создаёт уникальный `runs/<run_id>`: синтетическая круговая орбита L0, сравнение с аналитическим решением и независимым DOP853, ECSV и Parquet, метрики точности и provenance. Каждый вызов создаёт новый каталог. Возврат 0 означает прохождение проверки; 1 — ошибку. Это проверка среды, не малый научный атлас из §17.3 программы.

Проверена существующая Windows .venv с Python 3.10.6. Менеджер зависимостей — pip; единственная фиксация установленных версий — `requirements/windows-py310.lock.txt`. Это снимок окружения с точными версиями, без хешей дистрибутивов; чистая установка и перенос на другую ОС пока не проверены. Состав рабочих зависимостей — `pyproject.toml`. Не заменять окружение AstroBridge.

Для нового Windows-окружения с совместимым Python 3.10:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements/windows-py310.lock.txt
.\.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation -e .
.\.venv\Scripts\python.exe -m pip check
```

Текущее окружение переустанавливать не требуется. Скрипт запуска работает непосредственно из src. На другой платформе составить и проверить отдельную фиксацию, не переносить Windows lock как гарантию совместимости.

## Карта проекта

| Путь | Назначение |
|---|---|
| `STATE.md`, `PLAN.md`, `DECISIONS.md` | Продолжение работы, этапы и основания решений |
| `configs/` | Паспорт хозяина, физика, мера, разделение выборок, ресурсы, эксперименты |
| `docs/` | Математика, верификация, словарь, задачи, предсказания, литература |
| `references/` | Библиография и происхождение документов |
| `data/` | Запросы, исходные и обработанные данные, SPICE, манифесты |
| `src/submoon_research/` | Пакет исследования и независимые научные компоненты |
| `tests/` | Проверки численной корректности и сохранности результатов |
| `runs/` | Отдельные воспроизводимые исполнения |
| `results/` | Проверенные сводки, рисунки и цепочки доказательств |
| `reports/` | Отчёты по этапам, стоимости и научным ограничениям |
| `manuscript/` | План первой статьи и будущие публикационные продукты |
| `scratch/`, `temp_scripts/` | Локальные временные и исторические файлы вне научной цепочки |

Правила хранения — [docs/data_dictionary.md](docs/data_dictionary.md); условия перехода к основной серии — [docs/validation_protocol.md](docs/validation_protocol.md). Локальные пути находятся в игнорируемом `configs/paths.local.yaml`, образец — `configs/paths.example.yaml`. Резервная копия крупных данных пока не настроена. Облачные вычисления и платные поисковые квоты не включены.
