# W0-002: контракт малого геометрического запроса v1

Продолжение `W0-T002` после W0-R002/R003/R004. Это собственный новый набор стартов; он не устанавливает эпоху, оси или шкалу времени опубликованного архива.

## Постановка до запроса

Эпоха: **2000-01-01 12:00 TDB = JD 2451545.0 TDB**, выбрана для независимого маршрута. Второй контрольный момент через 60 секунд; он не является интеграцией исследовательской модели. Геометрические положения и скорости (`VEC_CORR=NONE`), фиксированные оси ICRF (`REF_SYSTEM=ICRF`, `REF_PLANE=FRAME`). +Z — полюс ICRF, +X — начало прямого восхождения ICRF, +Y дополняет правую тройку. Название ICRF не подменяется FK5/J2000. [Определения JPL](https://ssd.jpl.nasa.gov/horizons/manual.html#reference-frames), [параметры API](https://ssd-api.jpl.nasa.gov/doc/horizons.html).

Общий исходный центр — барицентр Солнечной системы `500@0`. Физические центры планет `599`, `699`, не барицентры систем `5`, `6`. Десять тел в конфигурации — объединение состава потенциального L1 для трёх хозяев: Солнце, Юпитер, Сатурн, Титан, Япет, четыре галилеевы луны, Гималия. Это состав входных данных, а не принятие сил или разрешение запуска L1.

AstroBridge получает AU-D; нормализуем в км и км/с: AU = 149597870.7 км точно, сутки = 86400 секунд TDB. Для хозяина h: `r_jh = r_jSSB - r_hSSB`, `v_jh = v_jSSB - v_hSSB`. Оси не вращаются; геометрические скорости преобразуются той же разностью. Нулевая строка хозяина сохраняется.

Проверяем преобразование также тремя прямыми запросами родительской планеты из центра хозяина. Всего **13 последовательных запросов × 2 момента**. Оценки точности эфемерид и ковариации отсутствуют: `null`, не нулевые ошибки. Версии источников извлекаются из фактических заголовков ответа; совместимость с GM паспортов отдельно подлежит проверке перед L1.

## Заранее заданная приёмка

- Схема AstroBridge принимает все запросы; реальные Python, пакет и workspace доступны.
- Успех без кэша и усечения, ровно два момента, правильные target/center, `ICRF`, `AU-D`, `TDB`, `NONE` подтверждены запросом и заголовком ответа; компоненты конечны.
- Обратное преобразование единиц: относительное расхождение ≤1e-15. Длины сверяются с колонкой RG: относительное расхождение ≤1e-12.
- Для каждого хозяина в обоих моментах разность SSB-векторов согласуется с прямым запросом планеты: норма ошибки положения ≤0.001 км, скорости ≤1e-8 км/с. Это допуски преобразования, не физические неопределённости.
- Исходные HTTP-ответы, Horizons-тексты, таблицы, запросы и манифесты AstroBridge сохранены и проверены SHA-256. Отдельный run хранит снимок кода, конфиг, среду, стоимость, статусы и ограничения. Локальный replay выполняется без сети и без перезаписи завершённого run.

Лимиты этой версии: один исполнитель, 600 с, 32 MiB выходов, ответ ≤1 MiB, HTTP timeout 20 с, без автоматических повторов и расходов. При сбое записывается отдельное неуспешное исполнение. Архив статьи и приложение AstroBridge не изменяются. На момент первого продукта v1 W0/W2 оставались открыты: генератор, силы/события и базовая динамика ещё не были реализованы.
