Реализация: `src/submoon_research/diagnostics/phase3_v2_input.py`, проверки: `tests/unit/test_phase3_v2_input.py`. Frozen v1, runs и владелец W2-T061 не изменяются; подключение к существующему runner не выполнено.

## Контракт

`load(root, audit_path, expected_audit_sha256)` требует переданный извне SHA-256 отчёта аудита W2-T064. Файл отчёта проверяется до чтения инвентаря; нельзя извлекать ожидаемый SHA из самого проверяемого отчёта. Для проверенного среза: `results/evidence/W2_phase3_audit_20261030/v1/audit.json`, SHA `0febe080e713cca4ea7cd6530beb46b7a89aa3f3fcff9b6bb17d69769e236150` (закреплён после исходного аудита, не до симуляций).

Все файлы инвентаря — 565 — читаются в проверенный по SHA/размеру снимок байтов с запретом выхода из root. Все последующие операции используют этот снимок, а не повторно читают файлы данных с диска. Отклоняются отсутствие файла, неправильный SHA, абсолютные/родительские пути, пустой инвентарь, ошибка audit/схемы и отличный набор блоков.

Слой дополнительно проверяет freeze конфигурации/набора и SHA manifest/units; независимо строит ожидаемый план и job fingerprint, отвергает пропуски/дубли/лишние и несовпадение полей. Проверяет 439 NPZ по SHA записи, форму, конечность, начальные состояния, согласие полной сетки с пробой; метки/времена и checkpoint — на структурную согласованность. Полная проверка математической достоверности NPZ-сетки и полных состояний была выполнена ранее W2-C101, не пересчитывается целиком здесь. Файлы верифицируются как снимок, не утверждается их независимое происхождение или качество наблюдений.

Архивный B: сверка всех 288 записей с планом, версией B, единицами и вычисленным архивным job fingerprint, начальной пробой, статусом и ошибкой. В выдачу для каждой орбиты B попадает только при полном совпадении данных единицы и горизонта. Для трёх стартов вне B144 возвращается `None` — не заменяется близким стартом. Одна строка B не является B-лестницей и сама по себе не доказывает сходимость.

Возвращаются 16 случаев для существующего прототипа, 439 строк, параметры и направления; unresolved сохраняются без подмены физической меткой. Входной слой **не вызывает classify или decision rules**, не создаёт выходные каталоги и не записывает файлы. Он не является универсальным загрузчиком других версий/серий: набор трёх run IDs и 439 записей задан для этого конкретного среза. Возможная потеря доверия к аудиторскому SHA, скомпрометированный код или конкурентная злонамеренная подмена памяти процесса не решаются одним хешем.
