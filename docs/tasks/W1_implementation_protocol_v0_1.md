# W1 — протокол реализации v0.1

Статус: draft, freeze запрещён. Реализация нормировок/генератора доступна;
статистический дизайн и независимые предсказания ещё не приняты.

Основной интерфейс: DomainSpec → generate → точные r/v и sampling-поля →
исходы с отдельными run_status/physical_outcome → оценки по рандомизациям.

Меры: исходная сетка отдельно; условные uniform(a,e,cos i,phases), uniform(log a)
и канонический объём. Сценарии физических параметров и внешних фаз отделены
от внутренних стартов. Базовый e_max=0.3, буфер=0.02; проверки буфера 0/0.05.
Изменение области требует нового domain_id и запуска. Плоскость старта
задаётся явным правым ортонормальным базисом в ICRF.

Горизонты-кандидаты: 10^4, 10^5, 10^6, 2×10^6 лет. Преобразование года,
конечные горизонты, число стартов, seeds научной серии и численные режимы
до реального пилота не фиксируются как принятые. 8×256 — проектный старт.

H1/H2/H3 сохраняются по досье W1. Количественное предсказание H3, семейство
сравнений, корректировка, критерии решений и правило остановки должны быть
зарегистрированы до проверочных исходов; сейчас их freeze-поля отсутствуют.
Для каждой гипотезы допустимы supported/contradicted/inconclusive.

Доступные функции статистики: приближённый интервал по рандомизациям,
парная разность с ковариацией, границы при нерешённых исходах. Полное V06
требует проверки покрытия на контролях и обоснования окончательного метода.

Следующий научный шаг: принять параметры/область реального генератора и
численный маршрут, затем измерить пилотную стоимость/дисперсию. После этого
закончить дизайн и создать хешированный freeze по guard contracts.freeze.
