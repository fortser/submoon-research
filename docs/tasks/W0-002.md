# W0-002 — Паспорта пилотных хозяев и контракт состояний

Основание: результат `W0-R001`, решение `W0-D003`, [аудит](../../reports/scientific/W0_baseline_audit.md). Задача не закрывает весь W0 автоматически.

1. Подготовить версионированные паспорта Япета, Ганимеда и Гималии: GM, определение радиуса, первичный источник/решение, версия, единицы, неопределённость, ковариации и статус отсутствующих данных. Аудитные числа из исходной статьи не переносить как принятые параметры.
2. Для Япета сверить 718 км из архива с определением среднего радиуса первичного источника; для Гималии отдельно разобрать отличие архивной массы от JPL GM и её большую неопределённость. Ганимед требует также решения по шести немодальным файлам.
3. Подготовить малый геометрический запрос по контракту origin/frame/epoch/time_scale, затем проверить реальную доступность AstroBridge, его Python и workspace. Не менять исходники AstroBridge.
4. Разделить неизменённые исходные состояния и собственные новые старты. Не восстанавливать неизвестную шкалу времени по слову «J2000» или по удобству интегратора.
5. Перед численным воспроизведением согласовать через решение рабочую версию L1; LL не переносить механически в параметр другого интегратора. Входы, силы и события должны пройти W2.

Выход: паспорта с источниками, контракт и малый набор геометрических состояний, хеши и отчёт о расхождениях. Готово, когда независимый исполнитель может восстановить каждый принятый параметр и состояние; нерешённые вопросы имеют явные ограничения.

Приёмка 5 октября 2026: паспортные входы, геометрический запрос, номинальная L1 v0.4.1 и базовый ансамбль трёх хозяев проверены. Подробности — [итог W0](../../reports/scientific/W0_completion_20261005.md). Точное воспроизведение авторского интегратора остаётся недоопределённым и не заявляется. Неизвестные совместные ошибки и формы ограничивают параметрические/физические контактные выводы; условный номинальный маршрут определён решением W0-D011. Ресурсы: малые локальные расчёты, без аренды.

Первый проверяемый продукт: [паспорт параметров Япета v1](../../data/processed/host_passports/iapetus_v1.yaml), [отчёт](../../reports/scientific/W0_iapetus_passport_v1.md) и [передача к остальному пилоту](../handoffs/W0_iapetus_to_remaining_passports_v1.md). Актуальный статус и ограничения — в журнале W0, а не в этой карточке требований.
