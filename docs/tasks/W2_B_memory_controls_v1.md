# Предложение W2-P012: разделить предикторную и компенсационную память IAS15

20.10.2026 · статус **proposed, не выполнено**. Основание: P011/C075/R026 и read-only аудит C078.

## Почему нужен новый контроль

Все physical restart P011 прошли окно отказа, включая P00 без переносов. Но fresh restart одновременно убирает предикторные коэффициенты, компенсационные остатки и меняет dt_last_done. Точное совпадение бинарных x/v не означает совпадения внутреннего компенсированного состояния. Поэтому результат P011 нельзя приписать только предикторной истории или только координатам.

## Общие входы и бюджет

Каждый вариант заново загружает один неизменный native snapshot C072 (SHA `9a634be5f9404ed88ccf66839aedc7133f4b38a27520e9d029e31dd78557b52a`). Все вмешательства происходят **только в памяти отдельного диагностического процесса**, до интеграции. Исходные бинарники/manifest не переписываются. x/v, GM, фигуры, время t, предложенный dt, epsilon, PRS23, min_dt и guard не меняются.

Общий target и 66 точек — буквальные grid из `results/evidence/W2_B_frames_20261019/matrix/inputs.json` (SHA `243acb30b4e5882911f10da99553ad10ff9052c421e720d70c0b266673b5a083`). До расчёта создать новые variant fingerprints с полной маской вмешательства. Сравнения при общих временах, не только по номеру шага.

1 worker/поток, последовательно; ≤60 s/10000 попыток на вариант, ≤90 s внешний предел процесса, ≤600 s всего, 2 GiB/256 MiB; без аренды/часового повтора. Остановка guard/лимитом — данные, не разрешение повторять или менять маску.

## Пять вариантов

| ID | Изменение относительно загруженного native |
|---|---|
| M0 | Никакого, только общий конечный target вместо далёкого 1000-летнего bound |
| MP | Обнулить **b/e/g/br/er/csb**; оставить csx/csv и dt_last_done |
| MC | Обнулить **csx/csv**; оставить все предикторные массивы и dt_last_done |
| MD | Только **dt_last_done=0**, все массивы сохранить |
| MA | MP + MC + MD |

M0 выполняется первым. До любого вмешательства M0 обязан точно повторить C073 (416 принятых шагов и тот же guard); тем самым проверяется отсутствие эффекта более близкого target до отказа. Если это не так — остановить весь пакет.

MP очищает br/er вместе с b/e, потому что при внутреннем отказе REBOUND может заново предсказать b/e из br/er. g вычисляется из b в начале попытки; csb обнуляется исходным кодом до PC-цикла. Они включены в маску для воспроизводимого полного сброса полиномиальной группы, а не объявлены независимыми причинами.

MC — изменение численного компенсированного состояния: при сохранённых binary64 x/v оно удаляет накопленные низшие разряды. **Это не строгое сохранение расширенного физического представления.** Вклад probe−host csx в исходном снимке имеет масштаб миллиметров; обязательно публиковать его и изменения состояния на общей сетке.

MD меняет условие восстановления предсказания после внутреннего отклонения шага. Это диагностическое вмешательство, не утверждение, что такой гибрид внутреннего состояния допустим для production.

`at/x0/v0/a0` не менять: исходник перезаписывает их в начале/в ходе шага. При gravity=basic `csa0=0` и перезаписывается нулями; его не включать в причинную группу. `steps_done` оставить неизменным во всех вариантах. Если выяснится иной режим gravity или несовпадение ABI — stop до пересмотра плана.

## Проверки безопасности и достаточности

- До/после вмешательства сохранить все scalar/array SHA, x/v/GM/figures, mask, размеры/типы ABI. Разрешены только объявленные поля; любое иное отличие запрещает интеграцию.
- Входные указатели должны быть непустыми, тип/element_size и N_allocated проверены по установленным descriptors; запись только в выделенный объём. Fresh NULL-поля не разыменовывать и не заменять указатели вручную.
- MA должна воспроизвести P00 по последовательности dt/next_dt и общим состояниям (те же время, target и физические x/v). Это проверка полноты выбранной маски, не научной точности. Если не совпала — нельзя объявлять группы полным эквивалентом fresh restart; отдельно искать оставшиеся отличия.
- Для всех вариантов публиковать target/guard/partial, первые расхождения относительно M0, min/квантили dt, a0/PRS23 по телам, общие временные точки и разности состояний. Никаких новых допусков траекторной приёмки.

## Различающие предсказания

Если одна MP/MC/MD проходит target при отказе M0, это устанавливает чувствительность данного кейса к этой группе, но не единственную первопричину. Если проходит только MA — эффект сочетания/неполная локализация. Если MC/MA помогают, нельзя трактовать это без оговорки об удалении низших разрядов координат. Если MA не воспроизводит P00, сначала выяснить неполноту маски. Возможен неопределённый результат.

После этого нужны отдельные проверки силы/производных и точности до принятия любого решения для основного B. Не разрешается молча превратить selective reset в штатный fallback.
