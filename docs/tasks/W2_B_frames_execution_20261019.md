## Численные уточнения до просмотра исходов

- Общая сетка: сначала 65 точек nominal elapsed от 0 до target; абсолютные binary64 метки получаются как t0+elapsed; добавить точное tf, удалить дубли, затем сохранить фактические elapsed=absolute−t0. Для временно сдвинутых вариантов использовать эти же elapsed; обратное сложение с t0 должно точно давать сохранённые absolute. Таким образом точки общие, а не отдельно округлённые сетки для разных вариантов.
- Сравнивать позиции, нормированные исходным радиусом пробы; скорости отдельно нормировать исходной относительной скоростью. Деление скорости на радиус не даёт безразмерной ошибки, поэтому не смешивать эти нормы. Нет порога научной приёмки; выводить абсолютные и нормированные разности, число общих точек и максимальный общий горизонт.
- Нативный baseline N сохраняет исходный bound=1000 лет и точную последовательность C073; P-варианты используют общий конечный target (прежнее tf+1000 s). Последний шаг P ограничивается их общим target. Сравнение N и P00 по шагам диагностирует изменение истории, но последнее ограничение горизонтом тоже явно различается.
- Выходы P относятся только к native-step динамике, без событий/production runner. Не называть достижение target физической выживаемостью. При guard сохранять последнее принятое состояние отдельно от состояния проваленной попытки.
- Все входы и experimental fingerprints сохранить до N; при несовпадении исходной попарной геометрии остановить пакет. SHA N, кода и входов закрепить перед запуском P; запуск P без принятого N запрещён.
- Каждый worker ограничен CPU affinity=1, потоками BLAS/OMP/Numba=1, RLIMIT_AS=2 GiB, RLIMIT_FSIZE≤240 MiB, 85 s GNU timeout +5 s kill. Внутри P — ≤60 s и 10000 попыток. Суммарно ≤600 s и 256 MiB; проверять место/объём между вариантами. Исходные snapshot/capture/replay не менять.

Краткие синтетические тесты нового экспериментального runner выполняются до реальной матрицы. Они не считаются дополнительными вариантами изучаемой орбиты. Сохранять failures/partials; никаких подборов или повторов по результату.
