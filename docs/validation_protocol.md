## Точность основных научных сравнений

Рабочие ориентиры программы: 3 п.п. для практически значимого различия, полуширина 95% интервала ≤1 п.п., численная чувствительность <0.5 п.п. Это цели, не достигнутая точность. Для Sobol единица ошибки — независимая рандомизация; пилот 8×256 на хозяина ещё не разрешённый производственный бюджет. При последовательном увеличении объёма определить правило остановки. Нужны интервалы разностей, учёт парности и множественных сравнений.

## Независимая проверка

1. Аудит прежнего использования: `configs/validation/splits.yaml`.
2. Запись количественного нового предсказания по `docs/templates/prediction.md` в `docs/predictions/`.
3. Фиксация модели, конфигурации, входов, uncertainty, допусков и критерия опровержения. Известные результаты литературы не считаются слепым тестом.
4. Freeze manifest с UTC и SHA-256; затем раскрытие/расчёт данных из `data/manifests/validation_sets.json`.
5. Сравнение и результат: supported / contradicted / inconclusive. Отдельно обозначать предсказание относительно численной модели и проверку реальными наблюдениями.
6. После подгонки отметить contamination и назначить новый тест либо признать отсутствие независимого подтверждения.

W7: отдельные серии для настройки/контроля, слепые инъекции, отрицательные области и глобальная ложная тревога. W8: искусственные каталоги проверяют метод, но не подтверждают природу. W10: разделение по хозяевам, не по соседним орбитам.
