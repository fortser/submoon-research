## Рекомендация

Вариант **A** (TR PRO 7995WX целиком), если на момент запуска есть verified-оффер с ≥ 90 физическими ядрами и ставкой ≤ $0.50/ч; иначе **B** (EPYC 9654 целиком) со сроком стенда 22.5 ч. Предел расходов **$12**, длительность ≤ 24 ч, рабочие процессы = числу физических ядер (не потоков, W2-T006). Порядок как в P2-1: preflight → аренда → проверка железа → удалённые гейты (pytest, ruff, короткий стенд + приёмщик) → полный стенд со сроком и стоп-файлом → контроль → выгрузка со сверкой SHA → destroy → проверка удаления.
