# Условное разрешение на быструю проверочную аренду — W2-D031

## Действующая поправка W2-D032 — 16.10.2026

Пользователь прямо отменил обязательное автоматическое удаление через полчаса без подтверждения и поручил арендовать найденную станцию для проверки фактических характеристик. **Независимый watchdog перед create больше не обязателен; отсутствие ответа само по себе не вызывает destroy.** Это отменяет соответствующие требования исторического текста W2-D031 ниже и прежний blocker W2-T027. Остальные пределы не расширены: одна оплачиваемая попытка, on-demand, 60 ГБ, ≤$0.75/ч, тест ≤30 минут/≤$1; основной научный прогон не разрешён. Отмена автоудаления не означает бессрочную аренду или увеличение бюджета; оператор обязан сообщать актуальное состояние и расходы и завершить/передать контроль по согласованному плану. Подробности исполнения: `results/evidence/W2_T027_hardware_20261016_0800/`.

Ниже сохранено исходное разрешение; в части watchdog/отсутствия ответа действует поправка W2-D032.

Источник: текущий диалог 2026-10-15. Пользователь принял предложение: «Хорошо, я принимаю твои предложения» и разрешил разработку радара. До этого явно принял автоматическое удаление при отсутствии согласованного продолжения за 30 минут. Это **новое отдельное разрешение**, не восстановление исчерпанных W2-D027/D028. Старые approval/attempts не обнулять.

## Разрешённые границы

- Пользователь сообщает, что появилась интересная станция; оператор читает [файл находок](interesting_stations.md), перепроверяет доступность и цену. **Монитор сам не создаёт контракт.**
- Семейство выбора: персонально 9975WX либо сопоставимый по прогнозу P2-2a CPU, проходящий `configs/compute/vast_radar.yaml` и профиль `p2_2a_station`: verified/unverified, amd64, вычислительный контракт, ≥64 доступных vCPU, доля ≥95%, RAM ≥64 ГБ, reliability ≥0.97, ≥28 модельных полезных физических worker. Проблемная machine 139652 исключена до доказательства исправления.
- Только on-demand, одна новая оплачиваемая попытка **всего по W2-D031**, не на каждый сигнал/перезапуск/машину. Платных повторов и замен после использованной попытки нет без нового разрешения.
- Ставка с контрактным диском **60 ГБ ≤$0.75/ч**. Поисковый интерес к самому 9975WX — ≤$0.65/ч; аналогам дополнительно верхние прогнозы ≤16 ч, ≤$11 вычисления+диск и ≤$13 с резервами.
- Проверка — **≤30 минут от создания контракта**, включая ожидание загрузки; не от первого SSH/running.
- Полный предел одной проверки **$1**, включая compute, диск и трафик. При продолжении эти расходы входят в ориентир/предельное планирование **$13** всей конкретной утверждённой серии P2-2a (9504 задания), а не всего W2/W1.
- Перед create подтвердить ставки трафика. При расходе максимум $0.375 на 30 минут compute+disk резерв до $0.625 не является автоматически разрешённым большим upload: объём заранее ограничить так, чтобы проверка целиком укладывалась в $1. Не загружать весь научный пакет для проверки железа.
- Проверить CPU-модель, доступные affinity/cgroup/quota, полезные физические ядра без SMT/E, RAM, SSH и базовую работоспособность. Короткий измерительный тест допустим; основной научный стенд автоматически **не разрешён**.
- **Нет явного согласия продолжить до абсолютного дедлайна → сохранить доступную малую диагностику и destroy.** Выгрузка/сбой диагностики не должны отменять или откладывать destroy. Stop не заменяет destroy. При ранней непригодности удалить раньше, без новой аренды.


## Быстрая оценка без переусложнения

Оператор сохраняет фактические полезные ресурсы, при необходимости измеряет короткую задачу. `scripts/vast_trial_estimate.py` считает тот же диапазон P2-2a, что finder, но с фактическими worker/quota/RAM и при наличии замером скорости ядра. Без замера используется каталог с честной маркировкой оценки. В итог включаются уже прошедшее время проверки, setup (консервативно), 1.5 ч на завершение и резерв трафика $1.

Пример JSON (только схема; числа ниже **синтетические**, не измерение арендованной машины):

```json
{"cpu_name":"AMD Ryzen Threadripper PRO 9975WX 32-Cores","physical_workers":32,"effective_vcpus":64,"ram_gb":257,"core_speed_ratio":null}
```

```powershell
.\.venv\Scripts\python.exe scripts/vast_trial_estimate.py --hardware <фактический.json> --hourly-usd 0.611111 --elapsed-hours 0.15
```

Это ориентир для обсуждения «примерно столько часов / долларов», не научный GO и не автоматическое согласие. Для продолжения нужны явный ответ пользователя, полный бюджет ≤$13 либо отдельно одобренное изменение, абсолютный срок новой аренды и новый режим контроля расходов; watchdog нельзя просто отключить без передачи контроля.

## Учёт и пересмотр

Перед платной попыткой зарегистрировать расходуемый token попытки с `approval_ref=W2-D031` в новом отдельном манифесте; после принятого API create попытка исчерпана даже при неудачном запуске контейнера. Не использовать старый `scratch/p2_rental/approval.json` без отдельной миграции. Секреты в манифест не писать.

Пять календарных дней от первого запуска радара без подходящей подтверждённой находки → индикация пересмотра бюджета. Выключенный ПК не приостанавливает календарь. Пересмотр не повышает ставку/бюджет, не создаёт новой попытки и не разрешает основной расчёт автоматически. Дата старта/первой находки сохраняется в SQLite, перезапуск отсчёт не сбрасывает.
