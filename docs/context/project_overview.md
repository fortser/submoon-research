# Общая картина исследования

Это постоянный краткий контекст для любого этапа. Текущее состояние — в [STATE.md](../../STATE.md); научные требования — в [исходной программе](../../Научная_программа_субспутники.md).

Очередность, допустимая параллельность и адаптация дальнейших задач: [RESEARCH_ROADMAP.md](../../RESEARCH_ROADMAP.md).

Цель: количественно установить, где субспутники могут сохраняться, какие механизмы определяют их судьбу и какие выводы о населённости допускают наблюдения. Связь программы: допустимые орбиты → физическая эволюция → источники/населённость → наблюдаемые данные.

Первая самостоятельная публикация: W0–W3 и ограниченный W4. Её вопрос — какие сравнительные утверждения о хозяевах сохраняются при контролируемом изменении меры, фаз, горизонта и критериев потери. W6, W8 и W9 не задерживают законченный динамический результат.

| Этап | Научный продукт |
|---|---|
| W0 | Проверенные параметры, исходная постановка и воспроизводимые старты |
| W1 | Меры, знаменатели, гипотезы H1–H3, интервалы и план выборки |
| W2 | Проверки физики/событий/интеграторов, сходимость, стоимость и рестарт |
| W3 | Атлас конечновременной выживаемости, контрольная группа и чувствительность |
| W4 | Подтверждённые механизмы и область применимости точечного хозяина |
| W5 | Условные времена жизни при связанной орбитально-вращательной эволюции |
| W6 | Ограниченные ядра рождения, удержания и разрушения |
| W7 | Наблюдательная полнота, кандидаты или условные верхние пределы |
| W8 | Идентифицируемые сочетания источников, потерь и обнаружимости |
| W9 | Отдельная проверка геологических сценариев хребта Япета |
| W10 | Проверенная переносимость на новые системы |

Основные хозяева: Япет, Титан, Каллисто, Рея, Ганимед, Феба. Контроль: Европа, Диона, Гиперион, Гималия. Луна — отдельный методический контроль. Пилот: Япет, Ганимед, Гималия. Контрольная группа не становится автоматически независимой: важно предшествующее использование её исходов.

Статус научного вывода определяется доказательствами. Сохранение до T не доказывает вечной устойчивости или населённости; хаос не равен потере; отсутствие детекции требует полноты. Неизвестные параметры маркируются, проектные пороги не выдаются за измерения. Подтверждение, опровержение и недостаточность данных допустимы.

Последовательность работы: постановка и данные → верификация → измерение эффекта → механизм → отложенная проверка → публикационный вывод с ограничениями. При недостатке ресурсов сокращается охват, сохраняется качество проверок. Облачные ресурсы рассматриваются по бенчмарку и только с прямым разрешением расходов.

Для конкретного этапа читать `docs/stages/Wn.md`, его обязательные контекстные блоки и реальные продукты предшествующих этапов. Полные исходные разделы в этих файлах воспроизводятся без сокращения; текущие задачи, результаты и ошибки берутся из журналов.
