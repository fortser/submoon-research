# 3. Объекты, данные и единая система обозначений

## 3.1. Состав объектов и контрольная группа

Основная группа: Япет, Титан, Каллисто, Рея, Ганимед и Феба. Предварительная контрольная группа: Европа, Диона, Гиперион и Гималия. Она нужна для проверки принадлежности к благоприятной группе, а не только порядка внутри заранее выбранных лидеров. До основного расчёта этот состав фиксируется после проверки физических данных и совместимости областей начальных условий. Замены допускаются по заранее описанным причинам доступности данных или вырожденности области, но не потому, что получен неудобный результат.

Земная Луна используется как отдельный методический контроль. Из отсутствия найденного естественного субспутника не выводится требование нулевой динамической выживаемости.

Пилот W0–W2: Япет, Ганимед и Гималия как контрастные конфигурации. Для физики фигуры целесообразен отдельный пилот на Ганимеде и Рее; окончательный выбор определяется качеством гравитационных данных. Для архивов выбирается один хозяин по подтверждённому покрытию и чувствительности, а не обязательно по первому месту в динамическом рейтинге.

Это целевая выборка, а не случайная выборка всех лун Солнечной системы. Выводы о распространённости среди всех лун потребуют отдельной модели отбора хозяев.

## 3.2. Паспорт входных данных

Для каждого тела хранить массу или GM, радиус и определение радиуса, фигуру, вращение, полюс, коэффициенты поля и их нормировку, орбитальное состояние, эпоху и систему отсчёта. Для каждого параметра указывать источник, версию, единицы, неопределённость или отсутствие её оценки. Ошибки параметров должны передаваться совместно, когда доступны ковариации; независимое варьирование связанных параметров запрещено без обоснования.

Для сверки масс и радиусов использовать первичные динамические решения и таблицы [JPL Solar System Dynamics](https://ssd.jpl.nasa.gov/sats/phys_par/sep.html). Таблица-агрегатор помогает обнаруживать несогласованности, но окончательное исследование должно указать исходное измерение и использованную версию.

Эфемериды и SPICE обеспечивают начальные состояния и наблюдательную геометрию в пределах покрытия файлов. Они не являются готовым миллиарделетним интегратором: длительную эволюцию необходимо считать в согласованной динамической модели. Архивные наборы SPICE и их метаядра описаны [NAIF](https://naif.jpl.nasa.gov/naif/data_pds_archived.html).

## 3.3. Обозначения

| Символ | Смысл |
|---|---|
| $M_p, m_s, m$ | Массы планеты, хозяина и субспутника |
| $R_s, R_b, \rho_b$ | Радиус хозяина, радиус и плотность субспутника |
| $a_s,e_s,P_s$ | Орбита хозяина вокруг планеты |
| $a,e,i,P_b$ | Оскулирующие элементы субспутника относительно хозяина |
| $\mathbf r,\mathbf v$ | Относительные положение и скорость в системе с фиксированными осями |
| $z$ | Полное начальное состояние субспутника и, при необходимости, его спина |
| $\theta$ | Физические параметры, начальные состояния массивных тел и параметры модели |
| $\mu$ | Нормированная мера распределения начальных состояний |
| $\tau,k$ | Время первого терминального события и его физический тип |
| $S_j(T;\mu,\theta)$ | Доля выживших до $T$ для хозяина $j$ при заданных условиях |
| $C_j(z)$ | Вероятность восстановления объекта наблюдательным поиском |
| $\eta,\Lambda_j$ | Доля хозяев с объектом заданного класса и среднее число объектов на хозяина; это разные параметры |
