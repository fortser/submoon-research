# Литература

Сначала проверить манифест и уже прочитанные источники. Для каждого утверждения нужны первичный текст, конкретная страница/формула/таблица, проверка и предел применимости. Исходная программа содержит сведения о статьях, но в новой рабочей базе они ещё не считаются независимо прочитанными.

`search_log.jsonl` — журнал операций; `evidence.csv` — утверждения источников; `baseline_audit.csv` — обязательные вопросы W0. Библиография находится в `references/`. DOI/сниппет/аннотация не заменяют методику. Платный клиент Tavily пока не реализован и не подключён.
