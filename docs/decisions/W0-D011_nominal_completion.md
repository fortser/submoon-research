# W0-D011 — Завершение номинального W0 и границы допуска

Принимается собственная номинальная L1 v0.4 для малого базового ансамбля W0.
Старые спецификации, данные и runs сохраняются. Это не production и не freeze W1.

GM физических центров Юпитера/Сатурна и спутников берутся из проверенных
JUP365/SAT441; номиналы пилотных хозяев сохраняются. GM Солнца берётся из
BODY10_GM gm_de440.tpc, а не из эффективного GM10 спутникового интегрирования,
включающего внутренние планеты. Пропущенные тела не добавляются к центрам
скрытой массой. Усечение системы остаётся структурным допущением L1.

J2 и его опорный радиус выбираются парой из одного решения: JUP365 для
Юпитера и SAT441 для Сатурна. Полюс фиксируется в ICRF на JD2451545.0 TDB.
Расчёт ориентации SPICE сверяется с независимым вычислением коэффициентов.
Ненормированный P2 не содержит повторного монополя. Фигура хозяина выключена.

Контактная модель — операционная сфера явно указанного сводочного радиуса
плюс 0.1 km для пробного тела. Неизвестные реальные форма и ковариации
сохраняются как null; они не запрещают условный номинальный расчёт, но
не допускают произвольного статистического ансамбля параметров. Для
пилотного расчёта year=365.25*86400 s; время интегрирования — секунды TDB.

Смешение DE441/DE442 подлежит измерению до базового ансамбля; поправка
или чувствительность записывается отдельно, исходные состояния не меняются.
Не утверждать согласие усечённой модели с полной эфемеридой на длительном T.

V02 v2 сохраняет допуски v1. Эталон решает задачу для фактически поданного
binary64 старта: округление в перицентре меняет энергию/период и усиливается
при высоком e. Эталон проверяется при 60 и 80 знаках. IAS15 epsilon=1e-12,
dt_initial=1e-5; DOP853 сохраняет прежнюю сетку допусков. Допуск IAS15
проверяется до e=0.99; DOP853 — до e=0.5. Прежний отказ DOP853 при высоком
e не объявляется исправленным. Базовые старты W0 имеют e<=0.3; критерии
реальной траектории/событий фиксируются до её расчёта отдельно.

Условие завершения W0: каждый пункт исходного досье имеет продукт и проверку,
малый базовый ансамбль трёх хозяев воспроизводим, исходы/аварии разделены,
неоднозначности статьи не переходят в собственную модель без определения.
Исторические дефекты остаются в отчёте; научные условия W1/W2/W3 не
объявляются выполненными по статусу W0. Полученные пилотные исходы являются
разработочными; они не служат независимым подтверждением H1–H3.
