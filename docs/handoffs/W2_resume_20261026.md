## 5. Как работать (уроки этой сессии)

- Порядок: Claude пишет код/тесты/.bat → пользователь запускает .bat и присылает лог; каждый шаг — предложение и согласование; запись в журнал после каждого шага (`scripts/project.py track add`, `validate`).
- Правило вывода фиксировать в журнале **до** расчёта; сохранять полные результаты, а не только сводку.
- В сессиях Claude, связанных с ПК через мост: удаление в папке проекта запрещено. `atomic_json` из такой сессии оставляет скрытый `.tmp` (переносить в `scratch/claude/_to_delete/`); `git status` оставляет `.git/index.lock` — вызывать git только с `--no-optional-locks`. Длинные команды не проходят (E2BIG) — писать файл и передавать его.
- REBOUND/REBOUNDx есть только в WSL пользователя; у Claude нет сети к PyPI.
- Внешние аудиты разбирать по пунктам, исправления — по отдельному «делай».
