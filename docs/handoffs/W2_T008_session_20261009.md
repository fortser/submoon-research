## Наблюдения, влияющие на план

- После исправления цена шага C ≈ 1.4 мс при ~15 вычислениях силы на шаг —
  доминируют накладные Python/DOP853 (кандидат этапа F).
- DOP853 перезапускается на каждой границе сегмента кеша: шагов заметно больше
  естественных ~57/период (Ганимед внутр. ≈94/период; внешние орбиты до 6729
  шагов). Снятие перезапусков — этап C плана, следующий по эффекту.
- Кеш целиком не масштабируется на 10 000 лет (≈9 МиБ на 20 периодов Япета) —
  нужен потоковый кеш блоками; размер блока подбирать под L3 целевой станции
  и проверять там, а не фиксировать заранее.
- Масштабирование TR PRO 7995WX по W2-T006: 1→184 потока ×34 (~18%); причина не
  установлена. Выбор между A и C требует многопроцессного замера.
