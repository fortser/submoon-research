# Восстановление выпуска 0.3.0

Пакет: `C:/submoon-research-backup/v0.3.0-20261005/submoon-research-v0.3.0-20261005.zip`.
Git bundle, wheel, lock и финальные аттестации хранятся рядом. Фактические SHA,
число файлов, release commit и результаты проверок находятся в
`results/evidence/backup_restore_v2.json` и receipt пакета; численные значения не копируются вручную.

1. Проверить SHA пакета по receipt/backup_restore_v2.json.
2. В новую папку: `python scripts/release_workspace.py restore --package <ZIP> --destination <новая-папка>`.
   Существующий каталог не перезаписывается; пути/размеры/SHA каждого файла проверяются.
3. Восстановить Git из bundle отдельно и дополнить научные входы/runs из ZIP.
   Для зарегистрированных научных файлов сохранять исходные байты; Git может менять переводы строк служебных текстов.
4. Подготовить Python 3.10 по `requirements/windows-py310-completion-20261005.lock.txt` и установить wheel 0.3.0.
   Снимок фиксирует версии, без хешей дистрибутивов. В проверенном восстановлении использована текущая .venv;
   установка всего научного окружения с нуля отдельно не подтверждена.
5. Запустить project validate, build_stage_briefs --check, pytest, Ruff и smoke,
   затем `scripts/verify_w0_completion.py --baseline-run runs/W0-baseline-20261005T112343Z-e6690074 --checks-only`.
   Полная приёмка без `--checks-only` повторяет также аудиты/replay и регрессии.

ZIP содержит код/конфиги/отчёты и оригиналы данных/завершённые runs на момент release commit.
После ZIP финальная аттестация backup и записи журнала добавляются в Git и как отдельные
файлы рядом с резервной копией; bundle после этих записей содержит финальную историю.
Так избегается попытка включить SHA ZIP в сам ZIP.

Секреты, .venv, configs/paths.local.yaml и scratch исключены. Для offline replay и
приёмки малой динамики приватная конфигурация AstroBridge не требуется. Новый сетевой
запрос требует собственных локальных путей внешнего приложения.

C — отдельный том; независимость физического устройства от T не установлена.
Разовая проверенная копия не является расписанием автоматического резервирования.
Предыдущий выпуск 0.2.0-r2 и его доказательства сохранены.
