# Исправления архитектуры W0 и вход W1

## Происхождение и запуск

`InputLedger` допускает научный вход только при ожидаемом SHA. Для выбранных
пользователем управляющих конфигов и реестров разрешена начальная регистрация
байтов; научные `source_paths` и состояния такого исключения не имеют.
Хеш, разбор и снимок относятся к одной версии байтов. Большие файлы сохраняются
как ссылки на неизменяемые оригиналы; пакет восстановления включает оригиналы.

`RunContext` создаёт manifest/validation до работы, сохраняет пакет кода и
конфиг, проверяет резерв и лимиты, завершает исключения и KeyboardInterrupt.
Внешние операции исполняются через `subprocess` с timeout. Disk budget
контролируется каждые 0.25 s и при финализации; wall — при каждом checkpoint.
Память не ограничена средствами ОС: этот профиль предназначен для малых
локальных проверок, не для production. Принудительное убийство самого Python
процесса не выполняет finally; надзор длительных W2/W3 ещё требуется.

## Контракты

L1 v0.2/v0.3 имеет отдельную неизменяемую закрытую схему. Pydantic запрещает
missing/extra, coercion, NaN/Inf; фиксированные научные поля сверяются точно.
Пути и SHA могут изменяться только при новой проверке происхождения. Новая
физическая постановка требует новой версии схемы, не ослабления старой.

v0.3 добавляет идентификаторы сил и событий. Реализации монополей, внешней
разности J2, E2 и операционного контакта доступны отдельно от интегратора.
E2>0 не доказывает постоянный уход. Контакт со сферой не считается проверенной
физической поверхностью. Локатор рассчитан на один разрешённый близкий проход:
несколько неразрешённых минимумов требуют деления шага.

## Генератор и знаменатель

`DomainSpec` задаёт GM, орбитальную полуось хозяина, операционную сферу,
размер пробного тела, e_max, буфер и явную опорную плоскость ICRF.
Hill использует круговой масштаб с множителем 3. Область:
`a(1-e)>=inner`, `a<=Hill`, `e<=e_max`. Пустая область — ошибка постановки.

Три условные плотности пропорциональны `1`, `1/a`, `sqrt(a)*e` по
`da de d(cos i) dM dω dΩ`. Их нормировки вычисляются до генерации.
Маргинальная CDF по e обращается численно, затем a генерируется из условной
CDF; rejection отсутствует, все точки имеют восстановимый знаменатель.
Рандомизированный Sobol использует явные seeds и номер рандомизации.
Версия генератора и точные r/v сохраняются. Каноническая мера не задаёт
меру рождения; круговые старты имеют отдельную условную меру.

Собственная 10×13 сетка фиксирует endpoints и коэффициент нижней границы.
Она не восстанавливает неизвестный авторский генератор: буквальный маршрут
читает оригинальные векторы.

## Статистика и freeze

Ошибка Sobol оценивается по независимым рандомизациям; t-интервал явно
приближённый. Парная разность сохраняет ковариацию. Нерешённые вычислительные
исходы остаются в знаменателе и дают границы доли. Полное покрытие интервалов,
множественные сравнения и остановка остаются продуктами W1, а не объявляются
доказанными по unit-тестам.

Guard freeze проверяет полноту H1–H3/split/протокола, хеши, реальный пилот,
его научный допуск и доказательства стоимости/дисперсии. Синтетические контроли
freeze не открывают. Генератор не принимает паспортные ошибки как независимые
Gaussian-параметры; неизвестные распределения не назначаются автоматически.

## Выпуск

Пакет содержит Git-файлы рабочего дерева и научные оригиналы/runs с SHA.
Секреты, среда, локальные пути, scratch и Git object store исключены.
Восстановление допускается только в новую папку; все пути и байты проверяются.
Локальный пакет и резервная копия на C имеют разные доказательства проверки.

Открытые научные зависимости: W0-I001–I007, внешние GM, J2/полюса, контакт,
численный режим, реальный пилот, checkpoint и стоимость реального ансамбля.
